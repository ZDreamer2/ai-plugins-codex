# AI Plugins for Codex

This repository contains the generated Codex distribution of [AI Plugins](https://github.com/ZDreamer2/ai-plugins).

## Install

Requires a Codex CLI version with `codex plugin` support and Git. Run in your terminal:

```sh
codex plugin marketplace add https://github.com/ZDreamer2/ai-plugins-codex.git
codex plugin add ai-doc@zd-plugins
codex plugin add ai-marketplace@zd-plugins
```

Install either plugin or both, then start a new Codex session. To refresh the marketplace, run `codex plugin marketplace upgrade zd-plugins`; use `/plugins` in Codex to manage installed plugins and their updates.

## Usage and documentation

See the [main repository](https://github.com/ZDreamer2/ai-plugins) for available plugins, examples and documentation. Building from source is unnecessary for installation.

## Source and changes
